전역 옵션

--json 응답을 JSON 포맷으로 출력 (--output json 단축)
--output default|json|compact 응답 포맷 지정
--project <path> 대상 Unreal 프로젝트 루트 디렉터리 지정
--force 파괴적 작업 또는 덮어쓰기 허용 (명령별 필요 여부 다름)
--wait compile / refresh 완료까지 대기 (해당 커맨드 전용)

에셋 워크플로 7개
asset find [--name <term>] [--type <type>] [--folder /Game/...] [--limit N]
언제든 가능
이름·타입·폴더 조건으로 에셋을 검색합니다. --name 또는 --type 중 하나는 필수.
asset info --path /Game/...
언제든 가능
에셋의 메타데이터(타입, 패키지명, 디스크 경로 등)를 반환합니다.
asset move --from /Game/... --to /Game/... [--force]
에셋을 새 경로로 이동합니다. 대상이 이미 존재하면 --force 필요.
asset rename --path /Game/... --name <newName> [--force]
에셋 이름을 변경합니다. 동일한 이름이 존재하면 --force 필요.
asset delete --path /Game/... --force
파괴적 작업
에셋을 삭제합니다. 항상 --force가 필요합니다.
asset create --type <kind> --path /Game/... [--force]
새 에셋을 생성합니다. 대상이 이미 존재하면 --force 필요.
지원 타입: material, texture, staticmesh, blueprint, dataasset, curve, soundcue
asset mkdir --path /Game/...
Content 폴더를 생성합니다. 중간 경로도 함께 생성됩니다.

level open --path /Game/... [--force]
레벨을 엽니다. 저장되지 않은 변경이 있으면 --force로 무시.
level inspect [--path /Game/...] [--with-values] [--max-depth N]
레벨의 액터 계층 구조를 반환합니다. --path 생략 시 현재 열린 레벨 대상.
level add-actor --class <ClassName> [--name <label>] [--location x,y,z] [--rotation p,y,r] [--scale x,y,z]
현재 레벨에 액터를 스폰합니다.
자주 쓰는 클래스: StaticMeshActor, PointLight, DirectionalLight, CameraActor, TriggerBox
level set-transform --actor <label> [--location x,y,z] [--rotation p,y,r] [--scale x,y,z]
액터의 Transform을 설정합니다. location·rotation·scale 중 하나 이상 필요.
level delete-actor --actor <label> --force

레벨에서 액터를 삭제합니다. 항상 --force 필요.
level list-components --actor <label>

level add-component --actor <label> --type <ComponentType> [--values <json>]
액터에 컴포넌트를 추가합니다. --values로 초기 프로퍼티 JSON 지정 가능.
level remove-component --actor <label> --type <ComponentType> [--index N] --force
파괴적 작업
액터에서 컴포넌트를 제거합니다. 항상 --force 필요.

액터의 메시 컴포넌트에 머티리얼을 할당합니다.

애니메이션 워크플로 6개
anim create-abp --skeleton /Game/... --path /Game/... [--force]
지정한 Skeleton으로 Animation Blueprint 에셋을 생성합니다. 대상이 존재하면 --force 필요.
anim assign-abp --bp /Game/... --anim-bp /Game/... [--component <name>]
Blueprint의 SkeletalMeshComponent에 Animation Blueprint를 연결하고 재컴파일합니다.
--component로 대상 컴포넌트 이름을 지정할 수 있습니다. 생략 시 첫 번째 SkeletalMesh가 대상.
anim list-states --path /Game/...
언제든 가능
Animation Blueprint의 상태머신 목록, 각 상태 이름, 정의된 변수 목록을 반환합니다.
anim add-variable --path /Game/... --name <varName> --type float|bool|int
Animation Blueprint에 변수를 추가하고 자동으로 재컴파일합니다.
지원 타입: float, bool, int
anim play-montage --actor <label> --montage /Game/... [--rate <float>]
PIE 필요
PIE 세션 중 지정한 액터에서 Animation Montage를 재생합니다.
활성 PIE 세션이 필요합니다. --rate 기본값은 1.0.
anim setup-statemachine --path /Game/... --idle-anim /Game/... --walk-anim /Game/... [--walk-threshold <float>] [--force]
Animation Blueprint에 Idle/Walk 상태머신을 만들고 Speed 변수 기준 전이까지 연결한 뒤 재컴파일합니다.
Speed(float) 변수가 없으면 자동으로 추가합니다. --walk-threshold 기본값은 10. 이미 상태머신이 있으면 --force 필요.

머티리얼 · 셰이더 워크플로 13개
material create --path /Game/... [--domain <d>] [--blend <b>] [--shading <s>] [--two-sided] [--force] [--save]
Material 에셋을 생성하면서 도메인 · 블렌드 모드 · 셰이딩 모델을 한 번에 지정합니다.
--domain: surface, deferreddecal, lightfunction, volume, postprocess, ui · --blend: opaque, masked, translucent, additive, modulate, alphacomposite, alphaholdout · --shading: unlit, defaultlit, subsurface, clearcoat, hair, cloth, eye, thintranslucent 등
material inspect --path /Game/... [--with-values]
언제든 가능
머티리얼 그래프 전체를 덤프합니다: 노드 목록, 각 핀의 연결 상태, 머티리얼 출력 핀(BaseColor 등) 연결.
여기서 나오는 노드 id를 connect · set-node · delete-node의 --node / --from / --to 값으로 그대로 사용합니다.
material list-node-types [--filter <term>] [--limit N]
언제든 가능
현재 엔진 빌드에서 사용 가능한 머티리얼 표현식(노드) 타입을 검색합니다.
예: --filter panner, --filter fresnel, --filter parameter
material add-node --path /Game/... --type <NodeType> [--name <id>] [--pos x,y] [--values <json>] [--no-compile] [--save]
그래프에 노드 하나를 추가합니다. --name은 이후 명령에서 쓰는 노드 id가 되며 그래프에 주석으로 표시됩니다.
--values로 노드 프로퍼티를 바로 지정: {"Texture":"/Game/T_Rock"}, {"ParameterName":"Tint","DefaultValue":[1,0.5,0.2,1]}
material set-node --path /Game/... --node <id> --values <json> [--pos x,y] [--no-compile] [--save]
기존 노드의 프로퍼티 값(상수, 파라미터 이름, 텍스처 등)을 수정합니다.
material connect --path /Game/... --from <id> [--from-output <pin>] (--to <id> [--to-input <pin>] | --property <출력핀>) [--no-compile] [--save]
노드 출력을 다른 노드의 입력 또는 머티리얼 출력 핀에 연결합니다.
--property: BaseColor, Metallic, Specular, Roughness, EmissiveColor, Opacity, OpacityMask, Normal, WorldPositionOffset, AmbientOcclusion, Refraction
material disconnect --path /Game/... (--to <id> [--to-input <pin>] | --property <출력핀>) [--no-compile] [--save]
노드 입력 핀 또는 머티리얼 출력 핀의 연결을 끊습니다.
material delete-node --path /Game/... --node <id> --force [--no-compile] [--save]
--force 필수
그래프에서 노드를 삭제합니다. 연결도 함께 해제됩니다.
material set-property --path /Game/... (--property <name> --value <v> | --values <json> | --domain/--blend/--shading/--two-sided) [--save]
머티리얼 자체 설정을 변경합니다. 친숙한 별칭(--blend translucent) 또는 UMaterial 프로퍼티 이름으로 직접 지정할 수 있습니다.
material apply-graph --path /Game/... (--graph <json> | --graph-file <path.json>) [--clear] [--layout] [--force] [--save]
노드 · 연결 · 출력을 담은 JSON 하나로 머티리얼 그래프 전체를 한 번에 구성합니다. 자연어로 설명한 셰이더를 구현할 때 주로 쓰는 명령입니다.
{"settings":{"blend":"translucent"}, "nodes":[{"id":"tex","type":"TextureSample","values":{...}}], "connections":[{"from":"tex","fromOutput":"RGB","to":"mul","toInput":"A"}], "outputs":[{"from":"mul","property":"BaseColor"}]} · --clear는 기존 그래프를 지우고 새로 만듭니다. 좌표를 지정하지 않으면 자동 정렬됩니다.
material compile --path /Game/... [--layout] [--save]
최대 120초
머티리얼을 재컴파일하고, --layout이면 그래프 노드를 자동 정렬합니다.
material create-instance --path /Game/... --parent /Game/... [--force] [--save]
지정한 부모 머티리얼로 Material Instance Constant 에셋을 생성합니다.
material set-instance-param --path /Game/... --name <param> --type scalar|vector|texture|switch --value <v> [--save]
머티리얼 인스턴스의 파라미터 값을 오버라이드합니다.
vector는 [r,g,b,a] 배열, texture는 콘텐츠 경로를 넘깁니다.

instances list
알려진 Unreal 프로젝트 인스턴스와 현재 활성 선택 항목을 반환합니다.
instances use <projectHash|projectPath>

doctor

raw --json '{"command":"..."}' [--force]
로우 프로토콜 JSON 봉투를 직접 전송합니다. 저수준 디버깅 전용.
