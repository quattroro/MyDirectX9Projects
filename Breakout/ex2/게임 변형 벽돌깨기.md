## 게임: 변형 벽돌깨기

### 화면과 오브젝트
- 캔버스 480x640.
- 화면 맨 위 y = 0 ~ 56 구간은 정보창(점수·최고점수·라운드·속력·콤보·라이프 표시) 영역이며 플레이 필드가 아님. 플레이 필드는 y = 56 ~ 640이고, 공·벽돌·아이템은 정보창 위에 그려지지 않음.
- 벽돌은 8열 x 6행, 크기 56x20, 간격 4. 벽돌 (col, row)의 위치는 x = 2 + col*60, y = 60 + row*24 + 하강량 (+ 라운드 진입 애니메이션 중에는 진입 오프셋).
- 패들은 80x12, y = 600에 고정, 이동 속도 420px/s, 화면 밖으로 나가지 않음.
- 공의 반지름은 6.

### 벽돌
- row 0이 맨 위. 점수는 아래 행부터 10/20/30/40/50/60 (row 5 = 10점, row 0 = 60점).
- 벽돌이 공에 맞을 때마다 체력이 1 줄고, 0이 되면 파괴.
- playing 상태로 10초가 지날 때마다 남은 벽돌 전체가 24px 아래로 내려옴. 서브 대기 중과 라운드 진입 애니메이션 중에는 이 하강 타이머가 멈춤.
- 어떤 벽돌이든 아래쪽 모서리가 패들 윗면(y = 600) 이상으로 내려오면 즉시 게임오버.
- 시드 난수로 서로 다른 위치 n곳을 특수 벽돌로 지정
- 여러 종류의 특수 벽돌들이 존재 
   1. 폭탄 벽돌 - 체력1, 맞추면 2초 뒤 주변 1칸 위치의 벽돌들을 함께 파괴
   2. 공 벽돌 - 체력1, 맞추면 파괴되면서 같은 위치에 vx 부호만 반대인 새 공 생성. 화면의 공이 이미 8개면 분열하지 않음.
   3. 단단한 벽돌 - 체력 2
   4. 버프 벽돌 - 체력1, 맞추면 파괴되며 버프 아이템을 하나 생성하여 아래로 낙하시킨다. 
   5. 라이프 벽돌 - 체력1, 맞추면 파괴되며 라이프 추가 아이템을 하나 생성하여 아래로 낙하시킨다. 

### 공
- 초기 속력 300px/s. 파괴한 벽돌이 10개 늘어날 때마다 속력 +5% (복리), 최대 600px/s. 바뀐 속력은 화면의 모든 공에 즉시 적용.
- 좌우 벽(x = 0, x = 480)과 천장에서 반사. 천장은 정보창 아래 경계인 y = 56이며, 공의 윗면(y - 6)이 56에 닿으면 반사 (공이 정보창 영역으로 들어가지 않음). 바닥 아래로 완전히 나가면 그 공은 사라짐.
- 패들 반사: 패들 중심에서 맞은 지점까지의 거리를 패들 절반 폭으로 나눈 값 t(-1~1)를 구하고, 수직 위 방향에서 t × 60°만큼 기울어진 방향으로 같은 속력으로 반사.
- 특수 공 생성 아이템을 획득하면 다음의 특수 공들 중 하나를 생성한다.
   1. 점착 공 - 패들에 닿으면 패들에 접착된 상태로 유지되고 마우스 좌클릭 또는 space버튼을 통해 공을 발사. 
   2. 위글 공 - 좌우로 왔다갔다 하며 나아가는 공
   3. 강철 공 - 체력 1짜리 벽과 충돌할 경우 첫번째 벽돌은 파괴 후 그대로 진행 두번째 벽돌의 체력 1을 감소시키고 튕겨져나온다. 체력 2 이상의 벽과 출돌할 경우 체력 2를 감소시키고 튕겨져 나온다.

### 라이프와 서브
- 라이프 3. 화면에 공이 하나도 남지 않았을 때만 라이프 1 감소.
- 라이프가 남아 있으면 공 하나가 패들 중앙 위에 붙은 상태(attached)로 대기하고, Space를 누르면 수직 위로 발사. 대기 중에는 벽돌 하강 타이머도 멈춤.
- 라이프가 0이 되면 게임오버.

### 라운드
- 라운드 1부터 시작. 모든 벽돌을 파괴하면 라운드 클리어이며 라운드 번호 += 1.
- 라운드가 끝나도 게임은 멈추지 않음. 필드에 남아 있는 공과 낙하 중인 아이템은 현재 위치, 이동 방향, 속력을 그대로 유지하고, 점수·콤보·라이프·공 속력·버프 지속 시간도 그대로 이어짐.
- 라운드 클리어 시 하강량과 하강 타이머는 0으로 초기화되고, 시드 난수로 새 벽돌 배치(특수 벽돌 n곳 포함)를 생성.
- 새 벽돌들은 정보창 뒤(필드 위쪽 바깥)에서 시작해 원래 위치(y = 60 + row*24)까지 위에서 아래로 내려오는 진입 애니메이션으로 등장.
   - 각 벽돌은 목표 위치보다 160px 위에서 출발하며, 0.9초 동안 ease-out으로 감속하며 내려옴.
   - 아래 행부터 0.06초씩 시차를 두고 출발 (row 5가 먼저, row 0이 마지막). 전체 약 1.2초.
- 진입 중인 벽돌도 충돌 판정이 있어 필드에 남아 있는 공과 자연스럽게 충돌함 (공이 맞으면 반사·체력 감소·파괴·점수 모두 일반 규칙과 동일).
- 진입 애니메이션 중에는 벽돌 하강 타이머가 멈춤.

### 아이템
 - 다양한 버프 아이템들이 존재하며 버프벽돌을 파괴하면 다음 아이템들 중 하나가 랜덤으로 출현
   1. 패들 2배 - 패들의 가로 길이가 2대로 늘어난다.
   2. 공 분열 - 공이 3개로 분열 기존 공은 그대로, 같은 위치에 vx 부호만 반대인 새 공 생성. 화면의 공이 이미 8개면 분열하지 않음.
   3. 공 배속 - 공의 속도가 1.5배 빨라진다.
   4. 공 감속 - 공의 속도가 1.5배 느려진다.
   5. 라이프 - 체력을 1개 증가시킨다.
   6 특수 공 생성 - 특수 공들중 하나를 랜덤으로 생성한다.

### 점수와 콤보
- 벽돌을 파괴할 때마다 combo += 1, 점수 += 벽돌 점수 × min(combo, 5).
- 체력만 깎이고 파괴되지 않았을 때는 점수와 콤보 변화 없음.
- 어떤 공이든 패들에 맞으면 combo = 0.
- 최고 점수는 localStorage 키 `breakout_highscore`에 저장하고, 새로고침 후에도 유지.

### 상태 전이
- title에서 Enter 또는 Space를 누르면 playing.
- playing과 paused는 P 키로 전환. paused 동안 시뮬레이션과 모든 타이머 정지.
- 모든 벽돌 파괴 시 상태는 playing을 유지한 채 다음 라운드로 진행 (위 "라운드" 참고). 별도의 clear 상태는 없음.
- 라이프 0 또는 벽돌이 패들 높이 도달 시 gameover.
- gameover에서 Enter를 누르면 title. title에서 새로 시작하면 점수, 라이프, 속력, 콤보, 라운드, 벽돌, 하강량, 타이머가 모두 초기화.
- esc를 누르면 게임 일시 정지와 함께 메뉴(계속하기, 다시시작, 게임종료)를 보여준다.

### 연출
- 벽돌 파괴, 패들 반사, 공 분실, 라운드 클리어, 게임오버에 효과음과 시각 효과를 넣을 것 (구현 방식 자유).
- 라운드 클리어 연출은 게임을 멈추지 않는 형태로 표시 (예: "ROUND N CLEAR!" 배너가 잠시 떴다가 사라짐).

## 기술 조건

- 결과물은 현재 폴더의 `index.html` 하나. CSS와 JS는 모두 이 파일 안에 작성. 외부 라이브러리, CDN, 이미지·사운드 파일 사용 금지 (사운드는 Web Audio API로 생성).
- 좌표계: 원점은 캔버스 왼쪽 위, y는 아래로 증가. 거리 단위 px, 시간 단위 초, 속도 단위 px/s.
- 시뮬레이션은 1/120초 고정 타임스텝으로 진행. 난수는 시드 기반 PRNG만 사용 (`Math.random` 사용 금지).
- 페이지를 열면 바로 title 상태로 실행되어야 함.
- 실제 키보드 입력도 동작해야 함: ←/→ 또는 A/D 이동, Space 발사, P 일시정지, Enter 시작/복귀.
- 자동 테스트를 위해 아래 API를 `window.game`으로 노출할 것.

```js
window.game = {
  reset(seed),          // 시드로 난수를 초기화하고 모든 것을 초기 상태(title)로
  step(dt),             // 시뮬레이션을 dt초만큼 진행 (내부에서 1/120초 고정 스텝으로 나눠 처리)
  input(key, pressed),  // key: 'Left' | 'Right' | 'Space' | 'P' | 'Enter', pressed: true(누름) / false(뗌) | 마우스 이동 | 마우스 좌클릭
  setAutoRun(enabled),  // false면 requestAnimationFrame 루프를 멈추고 step()으로만 진행. 기본값 true
  getState(),           // 아래 형식의 객체(복사본)를 반환
  debug: {
    setBalls(balls),    // [{ x, y, vx, vy }] 로 공 목록을 교체 (attached = false)
    setBricks(bricks),  // [{ col, row, hp, gold }] 에 있는 벽돌만 존재하도록 교체
    setLives(n),
    setPaddleX(x),      // 패들 왼쪽 끝 x
    setState(state)     // 'title' | 'playing' | 'paused' | 'gameover'
  }
};

// getState() 반환 형식
{
  state: 'title' | 'playing' | 'paused' | 'gameover',
  score, highScore, lives, combo,
  ballSpeed,                              // 현재 기준 공 속력 (px/s)
  elapsed,                                // playing 상태로 흐른 누적 시간 (초)
  round,                                  // 현재 라운드 (1부터)
  entering,                               // 새 라운드 벽돌 진입 애니메이션 중이면 true
  fieldTop,                               // 플레이 필드 천장 y (= 56)
  paddle: { x, y, w, h },                 // x, y는 왼쪽 위 모서리
  balls: [{ x, y, vx, vy, r, attached }], // x, y는 중심
  bricks: [{ col, row, x, y, w, h, hp, gold, alive }]  // y는 진입 애니메이션 오프셋이 반영된 현재 위치
}
```
